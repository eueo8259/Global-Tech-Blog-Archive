# 코드 리뷰 워크플로

## 목적

이 문서는 구현이 완료된 변경 사항을 독립적인 사전 코드 리뷰와 자동
PR 리뷰를 거쳐 `develop` 브랜치에 안전하게 병합하기 위한 절차를
정의한다.

코드 리뷰는 결함을 발견하고 병합 가능 여부를 판단하는 과정이다.
테스트, 빌드, 린트처럼 결과를 기계적으로 판정할 수 있는 검증은 로컬
검증과 CI가 담당한다.

## 전체 흐름

```text
Issue 정의
→ 구현
→ 사전 코드 리뷰
→ 리뷰 지적 수정
→ 로컬 테스트
→ 일반 PR 생성
→ Codex 자동 PR 리뷰 + CI
→ 리뷰 지적 수정
→ CI 재검증
→ Merge
```

사전 코드 리뷰를 통과한 변경은 Draft가 아닌 일반 PR로 생성한다. PR이
생성되면 Codex 자동 리뷰와 CI가 시작된다.

## 리뷰 단계

### 사전 코드 리뷰

PR을 생성하기 전에 구현 세션과 분리된 리뷰 세션에서 저장소 전용
`code-review` Skill을 사용한다. 현재 작업 브랜치를 `develop`과
비교하여 구현 결함을 조기에 발견하는 것이 목적이다.

리뷰 세션에는 다음 정보를 제공한다.

- 연결된 Issue 또는 변경 요구사항
- 기준 브랜치와 작업 브랜치
- 변경 의도와 주요 설계 판단
- 이미 수행한 검증과 그 결과

리뷰 세션은 파일 수정, stage, commit, push, PR 생성을 하지 않는다.
리뷰 결과와 통과 여부만 구현 세션에 전달한다.

### 자동 PR 리뷰

일반 PR 생성 시 Codex의 GitHub 자동 리뷰 기능으로 수행한다. 실제 PR
diff를 기준으로 병합을 막아야 하는 중요한 코드 결함을 검토한다.

Codex 자동 리뷰는 CI와 역할이 다르며 테스트, 빌드, 린트 검증을
대체하지 않는다. 자동 리뷰 규칙도 필수 테스트, 브랜치 보호, 사람의
승인을 대체하지 않는다.

## 리뷰 우선순위

- `P0`: 데이터 손실, 심각한 보안 노출, 광범위한 서비스 장애처럼 즉시
  대응해야 하는 중대 결함
- `P1`: 잘못된 동작, 중대한 회귀, 필수 요구사항 누락처럼 병합 전에
  반드시 수정해야 하는 결함
- `P2`: 구체적인 미래 비용이 확인되는 비차단 유지보수 또는 테스트
  문제

포맷팅, 린트 및 기타 결정적인 검사는 자동화 도구에 맡긴다. 재현 조건과
영향이 불분명한 추측성 의견이나 취향에 따른 지적은 리뷰 결과에 넣지
않는다.

## 리뷰 결과 형식

각 지적에는 다음 내용을 포함한다.

- 우선순위와 간결한 제목
- 정확한 파일과 최소한의 줄 범위
- 문제가 발생하는 조건
- 사용자 또는 시스템에 미치는 영향
- 필요한 경우 안전한 수정 방향

지적 사항이 없으면 `No findings`를 명시한다. 마지막에는 다음 중 하나로
판정한다.

- `PASS`: 열린 `P0` 또는 `P1` 없음
- `CHANGES REQUIRED`: 열린 `P0` 또는 `P1` 있음

`P2`는 사전 리뷰 통과를 막지 않지만, 수정하지 않는 경우 구현 세션에서
그 판단을 확인한다.

## 수정 및 재검토

구현 세션은 `P0`와 `P1`을 수정한 뒤 영향받은 동작을 검증한다. 수정이
리뷰 대상의 핵심 로직을 변경했거나 새로운 위험을 만들 수 있다면 별도
리뷰 세션에서 사전 리뷰를 다시 수행한다.

PR에 추가 커밋을 push한 경우 CI의 재실행 결과를 확인한다. Codex 자동
리뷰가 새 커밋에 대해 실행되지 않았거나 재검토가 필요하면 PR 댓글에
`@codex review`를 남겨 다시 요청한다.

열린 `P0` 또는 `P1`, 실패한 필수 CI, 해결되지 않은 병합 차단 리뷰가
있으면 병합하지 않는다.

## 자동 PR 리뷰 설정

- 저장소를 Codex Cloud에 연결한다.
- Codex Code Review 설정에서 저장소의 `Code review`를 활성화한다.
- 같은 설정에서 `Automatic reviews`를 활성화한다.
- 저장소의 `AGENTS.md`에 적용 범위별 코드 리뷰 규칙을 작성한다.

## 기존 Git 워크플로와의 관계

Issue, 브랜치, commit, PR 및 merge 규칙은 `docs/git-workflow.md`를 따른다.
이 문서는 그중 사전 리뷰부터 병합 승인까지의 리뷰 게이트를 보완한다.
